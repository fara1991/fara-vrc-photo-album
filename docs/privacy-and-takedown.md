### 要点（利用規約の本文から。条番号は取得時の版）

- 投稿したコンテンツの権利は本人が持つ（8.1）。他人の権利（プライバシー・肖像を含む）を侵害しないこと（8.4）。
- スクリーンショットや動画を撮って共有してよい。他人のワールド・アバターが写るときは、必要な許諾を得る責任は撮った本人にある（12）。
- 他のユーザーのコンテンツを許可なく共有・配布しない（13.2(c)。配信は例外）。
- 他のユーザーの個人情報を同意なく集めない（13.2(g)）。嫌がらせ・つきまとい禁止（13.2(n)）。
- ワールド・アバターの作者は権利を保持する（8.1）。購入コンテンツはプラットフォーム内でのみ使え、持ち出せない（9.2）。

### 要点（コミュニティガイドラインから）

- 個人を特定できる情報の公開（ドキシング）は、公開情報でも禁止。
- 同意のない親密な画像の共有は禁止（永久 BAN）。

### 本サイトの運用に落とすこと

- ワールドの作者へのクレジットとして、ワールドのページと VRChat 上のワールドへのリンクを必ず出す（M2。計画書 §4.1.2）。ライセンスで撮影・掲載が制限されているワールド・アバターは載せない（アップロード前の確認項目）。
- 2025 年 11 月より前の写真は載せない（ワールド情報が XMP に無いため。`ContentLoader` がビルドエラーにする）。
- アップロード用フォルダに入れた写真だけを掲載する（入れる = 掲載確認の印。計画書 §5.5・§7.2）。

## 削除依頼への対応（M4 までに確定する）

プライバシーポリシー（`/privacy`、`PrivacyView`）に書いてあること（M1 で雛形を更新）:

- **写っている方は、どなたでも**、写真の削除を依頼できる。
- 連絡先は **Twitter（@game_fara）か、サイトの「作者へ報告」（/report）**。
- 対応の目安は受付から **7 日以内**。
- **Discord は連絡先にしない**（Discord では受け付けない）。
- 報告フォーム（/report）の連絡先は **Twitter のユーザー名（@○○）が必須**（`@` + 英数字とアンダースコア 1〜15 文字。kit v0.4.0 の `ContactRequired` / `ContactFormat`。`Report.razor`）。検査は画面側のみで、Worker は連絡先の長さしか見ない。

手順:

1. 受付（Twitter か /report）。対象の URL・写真を特定する（本人確認は、可能な範囲で VRChat 上の表示名・ID の一致で行う）。
2. **写真ごとの削除**: `album remove <key>`（記事 JSON から外す → R2 の画像（`_640`/`_1280`/`_2048`/`_og`）を削除 → 台帳を removed）→ CDN・ブラウザのキャッシュを URL 指定で削除 → 再ビルド・公開。
3. 完了を依頼者に連絡する。記録は件名と日付だけを残す（個人情報を残さない）。

- 名前は Git に入らない（記事・台帳にも人名は書かない）。さらに `content/`（記事・台帳・アバターと服のマスタ）自体を Git に入れていないので、リポジトリをパブリックにしても、本物の記事の中身・元ファイル名・アバターの情報は出ない。履歴も、パブリック化のときに新しいリポジトリにまとめ直した。
